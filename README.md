# Hack Tracker
A desktop app that tracks cyber security incidents internationally. (updates upon a refresh) I use data gathered from RSS to access some news feeds along with some free apis that access up to date cyber security news.

To launch: inside of the hack-tracker folder, Execute the Hack Tracker shortcut. This will open the app, you may need to click the refresh button in the top right corner to start seeing updates.

This app was made with Claude Sonnet 5.
